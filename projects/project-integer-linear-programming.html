Integer/Linear Programming

This interactive notebook demonstrates four real-world optimization models using Pyomo in Python. Each problem applies Linear or Integer Programming to solve operational decisions such as minimizing cost or maximizing value under constraints.

  • 🔧 Fixed-Charge Plant Location: Choose which plants to open and how to ship products to meet demand at minimal total cost.
  • 📡 Cell Tower Coverage: Select tower sites to maximize regional coverage within a strict budget.
  • 🔬 R&D Project Selection: Choose projects to fund based on budget, staffing, and dependencies while maximizing Net Present Value (NPV).
  • 🚒 Fire Station Set Covering: Select the minimum number of fire stations needed to cover all regions.

▶️ Open in Google Colab

🧠 Built using Pyomo for modeling and solved with GLPK. Includes real-world logistics, coverage, and planning problems.
