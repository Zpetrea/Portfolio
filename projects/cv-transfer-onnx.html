Recyclables Object Detection (YOLOv8)

Project Overview

This demo uses a fine-tuned YOLOv8 detector to localize and label waste items (e.g., bottle, can, paper, plastic bag) and optionally map them to bins like Recycle or Landfill. The model you see running here is the same one used in my experiments; it’s packaged in a Hugging Face Space and embedded below with an interactive Gradio UI.

Tech Stack

Ultralytics YOLOv8 PyTorch Gradio Hugging Face Spaces

Try dropping in your own photo. Use the sliders to balance between recall (finding more items) and precision (fewer false positives).

How to use

  • Upload or drag an image into the widget.
  • Click Analyze (or it may auto-run) to get detections with bounding boxes & labels.
  • Tune the sliders if you want different behavior (see below).

What the sliders/scales do

  • Confidence Threshold Minimum model confidence for a detection to be kept. Lower = more boxes (higher recall, more false positives). Higher = fewer boxes (higher precision, may miss items). Try 0.35–0.55 for general photos.
  • IoU Threshold (NMS) Controls how much overlap is allowed between boxes after Non-Maximum Suppression. Lower (e.g., 0.35–0.45) removes more overlapping boxes (aggressive). Higher (e.g., 0.5–0.6) allows more overlaps (useful for crowded scenes).
  • Image Size Resize used at inference (e.g., 640). Larger sizes can catch smaller objects but are slower; smaller sizes are faster but may miss tiny items. Use the same size you trained with for best results.
  • Max Detections Upper bound on the number of boxes returned. If you’re getting many small false positives, lowering this can help tidy results.
  • Class Filter (optional) Limit predictions to specific classes (e.g., only bottle/can). Handy for focused demos.

Label → Bin mapping (optional)

The detector outputs item labels (e.g., bottle, can, paper). If the Space includes a post-processing step, labels are mapped to bins:

  • Recycle: bottle, can, cardboard, paper (if clean), some plastics
  • Landfill: plastic bag/film, food-contaminated paper, mixed/unknown

If you want this mapping adjusted, I can update the class→bin dictionary directly in the Space.
