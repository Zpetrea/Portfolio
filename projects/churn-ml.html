Customer Churn: End-to-End ML (Forecasts, Segments, What-If)

Project Overview

Interactive churn prediction built with scikit-learn and Gradio. The app predicts current churn risk, provides 3- and 6-month forecasts, segments customers (Low/Medium/High), and includes a What-If simulator to test discounts or contract changes. Global feature importance is visualized with SHAP.

Highlights

  • Preprocessing with ColumnTransformer (one-hot + scaling)
  • Calibrated classifier (reliable probabilities) and ROC-AUC reporting
  • Risk segmentation and future probability forecasts (3/6 months)
  • What-If retention simulator (e.g., 10–50% discount, 1-/2-year contracts)
  • Explainability via SHAP (global feature importance)

Tech Stack
Python scikit-learn SHAP Gradio Pandas
