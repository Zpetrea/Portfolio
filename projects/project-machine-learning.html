Machine Learning

Project Overview:

This machine learning project explores predictive maintenance using a dataset of 26,570 samples with 26 features, including sensor measurements, product codes, and categorical attributes. The goal was to predict whether a product would fail during quality inspection.

Data Summary:

The dataset contains a mixture of numerical and categorical features such as:

  • Sensor measurements (measurement_0 to measurement_17)
  • Product and material identifiers (product_code, attribute_0 to attribute_3)
  • Target variable: failure (Yes/No)
Missing values were common across sensor readings and handled via data cleaning prior to modeling.

Models Used:

Several models were evaluated for binary classification:

  • Logistic Regression
  • Decision Trees
  • Random Forests
  • Gradient Boosting (optional depending on additional steps)
Feature selection, correlation analysis, and data transformation were performed to enhance performance.

Key Findings:

  • Sensor features like measurement_17, measurement_5, and measurement_16 had strong correlations with failure.
  • Random Forests provided robust performance, handling missing data and feature interactions well.
  • Visualizations such as boxplots and histograms showed clear differences between failed and non-failed items across specific measurements.
  • Standardization and long-format reshaping improved EDA and model interpretability.
